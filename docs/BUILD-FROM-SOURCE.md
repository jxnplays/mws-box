# Always build from source

MWS&BOX does not distribute prebuilt binaries.

Clone the repository and build it yourself using the upstream IW4L instructions. This keeps the project transparent, lets anyone inspect the code, and avoids distributing anything that could be mistaken for a ready-to-run package containing game data.

## Quick start

```bash
git clone https://github.com/jxnplays/mws-box.git
cd mws-box
# Follow the upstream IW4L build steps in the original documentation
```

You must supply your own legitimate game installs. Nothing in this repository replaces or includes game files.

No releases with compiled executables will be published. The only supported way to run the client is to build it from this source tree.
