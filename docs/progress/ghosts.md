# Call of Duty: Ghosts

Ghosts is treated as a namespace / DLC category. It does not fork the core render path.

Released November 5, 2013 (Infinity Ward). Target content includes multiplayer maps, weapons (including the Marksman Rifle class), attachments, the point-based perk system, Create-A-Soldier, Extinction mode, and killstreaks.
