# blender-headless

**Purpose:** Run Blender operations without GUI.
**Tool:** Blender

## Command

```
blender --background --python <script.py>
```

## Expected IO

- **Input:** Python script + input files.
- **Output:** Depends on script (export, convert, etc.).

- Blender not installed on this machine. Download: https://www.blender.org/download/
