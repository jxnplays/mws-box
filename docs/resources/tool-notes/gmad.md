# gmad

**Purpose:** Unpack `.gma` files from GMod.
**Binary:** `steamapps\common\GarrysMod\bin\gmad.exe`

## Command

```
gmad extract <path-to-.gma>
```

## Expected IO

- **Input:** `.gma` file (GMod Workshop addon).
- **Output:** Extracted folder with `addon.json`, models, materials, etc.

## Notes

- GMod not confirmed on this machine. If missing, document and stop.
- `.gma` files are also produced by `gmconverter` for testing.
